> **R&D Projects Delivery:** An AI-powered career assistant built with **Llama 3.3 70B** to match CVs with Finnish job market demands.

## 🚀 Key Features
- **ATS Match Score:** Instantly see how well your CV matches a job advertisement.
- **Deep Gap Analysis:** Identifies strengths and specific career areas to improve.
- **Finnish Market Guide:** Provides a list of **25 real target employers** per role.
- **Unicode PDF Report:** Handles Finnish characters (ä, ö, å) perfectly using DejaVu fonts.

## 🛠️ Technical Stack
- **Backend:** Flask (Python)
- **AI Brain:** Groq API (**Llama-3.3-70b-versatile**)
- **PDF Engine:** FPDF2 with Unicode embedding
